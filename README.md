# DAT (Data Allocation Table)

A fully offline, single-file data viewer built for CSV, Excel, and OpenDocument files.

## Features
- No installation, no server, no internet required
- Works entirely in your browser
- CSV, Excel (.xlsx, .xls, .xlsm, .xlsb), and ODS support
- Sort, group, filter, highlight, and export your data
- Calculations panel with scope, type detection, and frequency tables
- Pre-import cleanup — exclude rows and columns before loading
- Bookmarks (markers), grouped view, pause mode, auto-fit columns, and more
- Export to CSV, Excel, TSV, or JSON
- Dark/light theme with persistent preferences

## Usage
Download `DAT_2.0.html` and open it in any modern browser. That's it.

- DAT_2.0 has been compiled with the SheetJS code
- DAT_2.0-CDN uses a content delivery network (CDN) to supply the SheeJS code
